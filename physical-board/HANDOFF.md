- **Everything lives on branch `physical-board`. Nothing of this may land on `main`** (public; the
  live game is served from it). Wyatt, 2026-08-22: *"i don't want any of this work to land on main in
  the public repo."* The folder was briefly on main (f8f7e24) and reverted (735b520); history keeps
  the files by his choice.
- **The main checkout stays on `main`.** Another session was live in it with uncommitted changes
  under `4/` (`git status` shows them), so this session never switched branches. Instead:
  - `physical-board/` is listed in `.git/info/exclude`, so on `main` it is invisible to git.
  - Commits go to the branch through a temporary index, never touching the working tree:
    ```bash
    export GIT_INDEX_FILE=$(mktemp) && git read-tree physical-board && git add -f -A physical-board \
      && T=$(git write-tree) && C=$(git commit-tree $T -p physical-board -F msg.txt) && unset GIT_INDEX_FILE \
      && git update-ref refs/heads/physical-board $C && git push -q origin physical-board
    ```
  - Last commit at handoff: `298fffd` (branch == origin). Local `main` and `origin/main` have
    diverged by a few planning commits each way that are NOT this session's business.
- zsh gotcha: `$C:refs/heads/x` — zsh treats `:r` as a modifier. Write `${C}:refs/heads/x`.

## 4. How to work it

```bash
node physical-board/generate.mjs                 # ~1 min; writes v3-round/*.svg/.dxf + site-data.js
python3 physical-board/art/trace.py physical-board/art/ingredients.json    # re-trace art (slow-ish)
python3 physical-board/fonts/extract.py physical-board/fonts/glyphs.json   # fonts (macOS system fonts)
```
Run `generate.mjs` under `perl -e 'alarm 300; exec @ARGV' node …` — a float-step loop once hung it
(fixed, but keep the cap). macOS has no `timeout`.

**QA = render and LOOK** (rule 19). The pattern used all session: inline each group's SVG from
`site-data.js` into a tiny HTML wrapper, screenshot with headless Chrome

Chrome you start; there is usually ANOTHER session's headless Chrome running (port 9762) — leave it.

## 5. Geometry lessons paid for (don't re-learn)

- `offsetPoly` is a mitre offset; near-parallel tiny segments shoot the join to infinity (mitre
  limit added); offsetting INWARD past a sliver folds the polygon — a notch plus a band around it
  must fit in the straight run between two rounded corners.
- `flatten()` must honour a circle's direction or a flattened ring fills solid when clipped.
- Raster shapes never overlap; holes are reversed sub-paths under nonzero (LightBurn fill modes
  cancel overlaps). Wedge polygons must be traced clockwise or their cut-outs vanish.
- Kerf: outward on outlines, inward on holes, decided by containment within the same `piece`.
- `notchPolyline` rotates the polyline to start far from the notch (a window straddling index 0
  otherwise deletes everything).
- Tracer: per-asset ink thresholds; "not red" keeps the cocoa wrapper open; morphological close
  heals the egg's nick; padded variants open the silhouette first or sparkle pixels grow blobs;
  `inkInset` drops ink near a coast; `blackbg` for the Chrome-rendered emoji.
- Chest hinge: both halves' holes 3.3 mm from their edge, tongue ends r 3.1 about the axle, strip
  body 2.4 → lid wall 9 mm = 3.3 + 2.4 + 3.3. Side play 0.15 per tongue.
