<planner_correction>
**`15-PATTERNS.md` proposes `CHAT_BUBBLE_HOLD_MULTIPLIER = 1.0`. That value is wrong and must not be used.**

Today `showChatBubble` (`src/ui/panel.js:335`) calls the shared `msgHoldMs(text)`, whose returned value is already scaled by `MSG_HOLD_MULTIPLIER = 0.8`. "Chat bubbles keep today's timing" therefore means the new chat-bubble curve must reproduce `round(clamp(raw, 1200, 7000) * 0.8)` — i.e. the new constant is **0.8**, not 1.0. Shipping 1.0 would make every bubble hold 25% longer than it does today, which is a change D-15 explicitly did not ask for.

The acceptance criteria below pin this by numeric equality against pre-change values, not by inspecting the constant, so the correct behaviour is enforced regardless of how the constant is spelled.
</planner_correction>
