## The single most useful thing built today

`docs/DRIVING-THE-GAME.md` **§8a — headless Chrome over CDP.** Per-animation-frame instrumentation,
no install, never touches Wyatt's screen. It found, in one session, three things that four rounds of
code-reading had missed:

- the box resizing during the fade
- `panel("")` firing between every message, so the fade was never running on 8 of 9 swaps
- 110 DOM mutations behind the welcome-screen blur

**Use it before optimising anything.** Especially the CPU work — the render path is where BUG-01
came from.
