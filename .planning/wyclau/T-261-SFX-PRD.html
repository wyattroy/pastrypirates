5. The ambient sea bed — cost, not aesthetics

PP_SFX_Ocean_Loop.mp3 is 365 KB — a 15–30s loop plus randomly scattered gulls/creaks on top, as your sheet describes. docs/AUDIO.md already has the mechanism worked out: MP3 pads silence on both ends, so looping needs loopStart/loopEnd markers set inside the decoded buffer, not a naive full-file loop — that's a code change, not just a file drop. The .wav sibling (2.8 MB) should never ship; the doc already rules WAV out on size (~10 MB/minute) and the MP3 is the delivered alternative.

Also blocking: initAudio() currently await Promise.all(...)s every SFX file before anything can play. Adding a ~365 KB bed to that same list means every sound effect in the game goes silent on a phone until the whole bed has downloaded. It needs its own load path that fades in when ready — already flagged in docs/AUDIO.md §3, not a new finding, just a real cost of doing this.
