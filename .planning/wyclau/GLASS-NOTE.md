**The pictures were 17.79 MB when you asked. They are 3.89 MB now — a 78% cut, and every one of
them is still exactly the size it was on screen.** The board went this morning; this is the rest of
it. The game downloads 2.1 MB less than it did at breakfast, and that 2.1 MB was all on the boot
path, so it comes off the wait before you can play rather than off some folder total.

**Where it came from:** the seven islands went from 1.67 MB to 0.35 — one of them, 636 KB, is now
64. The dock, 110 KB to 14. The four boats, 45 KB each to 9. The ingredient crates, 0.36 MB to 0.11.

**I left 90 pictures completely alone, and that's the part I'd want you to know about.** Nearly all
the small flat icons come out BIGGER in the new format — it's built for painted artwork, and a flat
two-colour icon is the one thing the old format already wins at. Converting them would have made
the game slower and softened your art to do it. So they kept their old format, and the tool now
refuses them by rule rather than by my judgement on the day.

**⚠ But "left alone" isn't "finished", and the report first said it in a way that read like it
was.** Those icons are settled on FORMAT only. The other half of your sentence — *"resized
according to its maximum pixel size in the real gameplay"* — has never been tried on them, and
there are measurements suggesting some are several times bigger than any screen asks for. That is a
separate job and it is written down as one.

**One thing broke and one thing I got wrong.** The conversion silently broke eight ingredient
pictures on the About page — every check said fine, because they all read the game's code and none
of them read the About page's HTML. Fixed, and the check reads HTML now. And I predicted the
"lossless" setting would rescue those flat icons; it won for **one file out of 121**. Written down
with the date on it so nobody assumes it next time.

*Not sailed: a full sea trial cannot be started from an unattended watch, so this rests on both
browser engines opening both games with every picture decoding, plus before/after photographs of
the worst-changed art. Strong, but not a voyage — saying so rather than letting the silence imply
one.*
