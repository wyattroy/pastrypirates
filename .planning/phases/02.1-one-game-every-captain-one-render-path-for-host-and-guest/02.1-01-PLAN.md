<objective>
Make a guest's copy of `appState.game` tell the truth. Today it is a photograph taken the instant the
voyage began and never updated again — the host simulates, the guest only ever appends to
`events[]`. Every renderer that reads `appState.game` directly (the day counter, the wind pill, every
camera cut) is silently wrong on a guest as a result. This plan fixes the one place that lies —
`watchEvents()` — and proves that the six known symptoms (day counter, wind pill, sail-window camera,
battle camera, storm camera, and the render sites' underlying position data) disappear without
touching any of the six files that display them.

Purpose: this is the tracer, and it is also THE state-layer fix Wyatt's sequencing ruling asks for
first. It touches the one seam every later plan in this phase depends on being true: Plan 02 (the
flat-card bug) and Plan 03 (the shared prompt renderer) both assume a guest's board state is honest by
the time they run. Nothing else in this phase can be verified against a correct baseline until this
lands.

Output: one corrected `watchEvents()`, and a red/green two-browser proof that the bug was real and is
now gone — the same instrument run twice, unmodified, on either side of the fix.
</objective>
