<objective>
Collapse the two hand-mirrored prompt renderers into one. `localAsk` (host, `4/src/ui/flow.js:181-280`)
and `watchPrompt`'s ask branch (guest, `4/src/orchestrator.js:1241-1309`) build the identical button row
from two separately-maintained pieces of code — the orchestrator's own comment at `:1286` calls this
"a genuine second copy... so a change to one that skips the other reintroduces the bug on whichever
side was forgotten." Six fields have already drifted and been caught one at a time across this
project's history (`disabled`, `why`, `back`, `flipIdx`, `stage`, `shorts`); this research found a
seventh (`seat`) still missing. This plan closes all seven at once by sharing the one function that
turns an option list into button HTML, and adds the automated gate this exact bug class has never had.

Purpose: this is the second half of Wyatt's own framing — "one architecture that displays things for
every player" — landing after the state layer (Plan 01) is honest and the flat-card bug (Plan 02) is
closed, so this plan's own verification is measuring only what it changed.

Output: one shared button-row builder, the missing `seat` field wired across the network, a red-proofed
static parity gate, and a live two-browser check.
</objective>
