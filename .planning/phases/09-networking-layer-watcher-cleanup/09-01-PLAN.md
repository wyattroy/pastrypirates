<objective>
Prove the phase's single load-bearing architectural bet end-to-end on one thin slice before migrating seventeen more watchers on top of it: that a watcher can be attached through a registry in `src/net/`, have its callback body stay verbatim in `index.html`, be individually detached again by exact callback reference, and be re-attached — all in one page load, with session-scoped listeners surviving the room-scoped teardown.

Three of the eighteen watchers move: `rooms/{room}/flip` (room scope) and the two inside `watchPresence()` — `.info/connected` and `presence` (session scope). Both scopes are in the tracer deliberately. The room-vs-session distinction is architectural, not incremental: if `detachRoom()` cannot spare the connection watchers, the design is wrong, and discovering that after fifteen more migrations costs fifteen commits instead of one.

That makes 09-04's contract check face RESEARCH Pitfall 4's live condition rather than a hypothetical one.

Purpose: de-risk the seam, the scoping, and the NET-03 observation method before the bulk migration.
Output: `src/net/` with a working registry, three migrated watchers, a Node unit test with its red path demonstrated, and a recorded same-tab attach → detach → re-attach transcript.

**Registry API** (`src/net/registry.js`)

- `attach({ scope, ref, event, callback, cancelCallback, label })` → `id` (number). Computes `key = scope + "|" + ref.toString() + "|" + event + "|" + (label || "")`. If an entry with that key already exists, logs a named `console.error` and returns the existing id **without attaching a second listener**. Otherwise calls `ref.on(event, callback)` — or `ref.on(event, callback, cancelCallback)` when a cancel callback is supplied — stores `{ id, key, scope, ref, event, callback, label, path }`, and returns the new id.
- `detach(id)` → `boolean`. Looks the entry up; calls `entry.ref.off(entry.event, entry.callback)` with the exact stored Reference and the exact stored function; deletes the entry.
- `detachRoom()` → count. Detaches every entry whose `scope === "room"`. Never touches `"session"`.
- `detachAll()` → count. Detaches everything.
- `size(scope)` → number. Omit `scope` for the total.
- `list()` → array of `{ id, scope, event, label, path }`. Deliberately omits `ref` and `callback` so the result is JSON-serialisable from a browser console.

Exactly two scopes exist: `"session"` and `"room"`.

**A. `src/net/registry.js`.** Implement the registry exactly as specified in this plan's artifacts register. Module-level `Map` keyed by a monotonically increasing numeric id.

One deliberate refinement of the skeleton in RESEARCH §"Code Examples": **`attach()` itself performs the `ref.on(...)` call.** In the research sketch the watcher called `.on()` and then told the registry about it. Putting the call inside `attach()` is what makes D-04's "no `.on()` call may bypass the registry" mechanically true and lets 09-04's contract check be a single-file exemption rather than a judgement call. Record that reasoning in the file header so a later reader does not "simplify" it back.

Preserve the third argument. `watchPresence()`'s two listeners each pass a cancel callback as `.on()`'s third parameter; that is what makes a permission-denied `presence` node fail silently instead of spamming the console. Accept it as `cancelCallback` and forward it. Dropping it would be a silent behavioural regression that no count-based test would notice.

Store the original `Reference` object handed in. Never store a path string and rebuild a Reference at detach time. Detach uses the two-argument `ref.off(event, callback)` form with the exact stored function. Explain both choices in the header, citing D-03 and RESEARCH Pitfall 1.

Duplicate refusal must be loud — a `console.error` naming the offending key and pointing at a double-invoked room-join as the likely cause — and must not attach a second listener. This turns leak vector (b) from a latent leak into a visible dev-console error.

No imports at all. This file has no dependency on UI, engine, shared, or app state.
