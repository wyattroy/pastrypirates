<objective>
Turn the phase's three one-shot manual checks into a committed, repeatable gate, and prove mechanically that the ~950 lines that moved arrived unchanged.

RESEARCH.md flagged all three as Wave 0 gaps with no existing tooling: the purity grep (ENGINE-01), the `ORDER IS LOAD-BEARING` annotation count (ENGINE-04), and the shared-to-engine DAG direction (SPLIT-01/02). A grep run once during execution and pasted into a SUMMARY proves nothing about Phase 9, 10 or 11. A committed check wired into `npm test` does.

The fourth assertion — moved-symbol export completeness — closes the failure class RESEARCH Pitfall 1 names: a symbol moved into a module but not exported, producing a `ReferenceError` only on the code path that touches it, which for `rollStorm` or `PERP` means only during a live game the 30-seed corpus cannot reach.

Purpose: make ENGINE-01 and ENGINE-04 enforceable rather than aspirational.
Output: `scripts/engine_contract_check.js`, a wired `npm test`, an updated module contract doc, and a pure-motion audit.
</objective>
