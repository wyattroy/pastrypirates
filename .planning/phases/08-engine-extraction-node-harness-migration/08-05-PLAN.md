<objective>
Close the two things left after the extraction: prove in a real browser that the page still plays with the engine outside `index.html`, and re-base `engineSourceHash` without going anywhere near `--capture`.

The browser check exists because the corpus has a structural blind spot D-17 names explicitly: 30 seeds of `Game.play()` in Node would stay green even if the page never rendered. RESEARCH Pattern 3 sharpens that — the classic live turn loop at `index.html:4746`+ is a hand-written reimplementation of the round logic that calls `game.r()` directly, uses a second-gust `windNow2`/`PERP` mechanic `Game.play()` never touches, and reaches a dozen `Game` instance methods from outside the class. A green corpus says nothing about any of it.

The re-base exists because `--capture` is currently the only write path to `manifest.json`, and it replays and re-hashes all 30 seeds as a side effect of writing anything. Running it to "just fix the source hash" would silently rewrite the frozen per-seed hashes — D-01's forbidden failure mode, arrived at by accident rather than intent.

Purpose: close the phase honestly.
Output: a verified browser playthrough including a forced storm, and a one-line manifest change in its own commit.
</objective>
