**The race-with-timeout wrapper every branch of the new dispatch must keep returning something

```js
export function withShotClock(seat,base,defaultVal){
  if(!appState.isHost||seat!==appState.shotClockSeat)return base;
  return new Promise(res=>{
    let done=false;
    appState.shotClockForce=()=>{if(!done){done=true;res(defaultVal);}};
    base.then(v=>{
      if(!done){
        done=true;appState.shotClockForce=null;
        if(appState.shotClockStash&&appState.shotClockStash.seat===seat)appState.shotClockStash=null;
        if(appState.shotClockSeat===seat)stopShotClock();
        res(v);
      }
    });
  });
}
```

### `4/src/net/writers.js` — publish pattern to copy

**Analog:** existing `netSetPrompt`/`netRemovePrompt`/`netSetResponse` (`4/src/net/writers.js:69-79`) —
already the right shape, no changes needed to their bodies, only to WHO calls them and under what guard:
```js
export function netSetPrompt(db, room, payload, onError) {
  return withReporter(db.ref("rooms/" + room + "/prompt").set(payload), onError);
}
export function netRemovePrompt(db, room, onError) {
  return withReporter(db.ref("rooms/" + room + "/prompt").remove(), onError);
}
export function netSetResponse(db, room, payload, onError) {
  return withReporter(db.ref("rooms/" + room + "/response").set(payload), onError);
}
```
**CRITICAL — no `db` null guard on any of these.** Confirmed by reading the bodies: bare `db.ref(...)`.
This is Pitfall 1's load-bearing fact. Any new call site touching these three functions must be
gated `if(db && room)` at the CALL SITE (matching `netNarrate`'s guard above), never inside these
functions (which would silently change behavior for every existing correct caller too).

**Guard convention already used elsewhere in the SAME watchers file for the analogous case** —
`netWatchTurnOrder`/`netWatchRecipes` (`4/src/net/watchers.js:148-158`):
```js
export function netWatchTurnOrder(db, room, handler) {
  if (!db || !room) return null;
  const ref = db.ref("rooms/" + room + "/turnOrder");
  return registry.attach({ scope: "room", ref, event: "value", callback: handler, label: "turnOrder" });
}
```
Note the asymmetry the research flags: `netWatchPrompt`/`netWatchDraftPrompt` (below) carry **no**
such guard today ("No guard at the call site this replaces — none added here" — deliberate, matching
the call site). Do not add one to those two without checking the call site first; do follow this
`if(!db||!room)return null` shape for any brand-new watcher this plan introduces.

```js
export function netWatchPrompt(db, room, handler) {
  const ref = db.ref("rooms/" + room + "/prompt");
  return registry.attach({ scope: "room", ref, event: "value", callback: handler, label: "prompt" });
}
export function netWatchResponse(db, room, handler, label) {
  const ref = db.ref("rooms/" + room + "/response");
  return registry.attach({ scope: "room", ref, event: "value", callback: handler, label });
}
```

## Shared Patterns

### Mirror-when-remote (the ONE pattern this whole plan applies to a new channel)
**Source:** `4/src/orchestrator.js:308-311` (`netNarrate`) and `4/src/ui/util.js:1781-1786`
(`applyActiveSeat`).
**Apply to:** the new prompt dispatch in `4/src/ui/util.js`/`4/src/ui/flow.js`.
```js
if(appState.isHost && appState.db && appState.room) netSetPrompt(appState.db, appState.room, payload);
```
Local render/resolve always happens unconditionally; the Firebase write is always gated by this exact
three-part condition. Never route the host's own decision through `netSetPrompt` without it (Pitfall 1).

### Local-vs-remote decision gate
**Source:** `4/src/ui/util.js:1788,1804` (`seatLocal`, `decisionIsLocal`).
**Apply to:** any new dispatch's fork condition. Use `decisionIsLocal`, never `seatLocal` directly,
for anything that must also work in pass-and-play (both `ask()` and `pickCell()` already do this
correctly — this is confirmation, not a change).

### Shot-clock compatibility
**Source:** `4/src/ui/util.js:1949-1963` (`withShotClock`).
**Apply to:** every branch of the new dispatch — it must keep resolving/returning a plain Promise so
`withShotClock` can wrap it exactly as it wraps `ask()`'s and `pickCell()`'s `base` today.

### Firebase writer null-guard convention
**Source:** `4/src/net/writers.js` (no guard, bodies are bare `db.ref(...)`) vs.
`4/src/net/watchers.js:148-158` (`if(!db||!room)return null`).
**Apply to:** guard at the CALL SITE for writers (matching `netNarrate`'s pattern), guard INSIDE the
function for any brand-new watcher (matching `netWatchTurnOrder`'s pattern) — these are two different,
both-correct conventions already coexisting in this codebase; do not unify them into one style.
