|----------|-------------|
| any browser → Firebase RTDB `rooms/*` | Ungated writes; anyone with a code can write any room node |
| host browser → guest browser (via `rooms/<C>/prompt`, `/narr`, `/ev`) | Host-composed strings are rendered into a guest's DOM |
