<objective>
Leave exactly one bot planner in the engine.

`4/src/engine/index.js` carries a whole second whole-turn planner and four helpers that only it
calls, preserved byte-identical to serve as the control arm of a head-to-head that has already been
decided. `planTurn` dispatches unconditionally to the shipping race planner, so none of it runs.
Wyatt, 2026-08-18: *"we should never use the old bot brain, it's done. Bot tuning should be done with
the newest algorithm that is actually used in game... this follows one of my design principles —
elegance."* (D-05)

Purpose: dead code that looks like a tuning target is worse than no code — a future tuning pass can
aim at it and measure nothing. This is also the last structural change to the engine before Phase 3
freezes its behaviour.

Output: the dead subtree removed, its stale comments removed with it, and
`4/scripts/planner_singleton_check.js` gating the result.
</objective>
