    Harden `windSetDotCount(n)` and extend the HUD so the dial is correct at both ends and operable
    with a thumb.

    **Clamping (defence in depth, `19-RESEARCH.md` §Security Domain).** `windSetDotCount` coerces
    with `Number(n)`, returns without changing anything when the result is not finite, then applies
    `Math.max(0, Math.min(WIND_DOT_MAX, Math.floor(...)))`. The range input's own `min`/`max`
    already stop a human from leaving the range; this clamp is what stops a later code path from
    doing so. After clamping it writes the value back into `#windDial.value` and `#windDialNum` so
    the on-screen number can never disagree with the live pool.

    **Exactly zero, with no residue.** When the clamped count is 0, `buildWindDots` removes every
    `.wdot` node from `.wlayer` so `document.querySelectorAll(".wdot").length` is 0, and
    `windDotLoop` writes no dot transform on any subsequent frame. The frame loop itself keeps
    running: the meter must still be able to sample the board's behaviour with the dots off, which
    is what makes the off-state baseline measurable in 19-05. Say this explicitly in the code
    comment so a later reader does not "fix" it by cancelling the loop.

    **Exactly one hundred.** At a clamped count of 100 there are exactly 100 `.wdot` nodes — assert
    this by construction in `buildWindDots` (grow to exactly `count`, shrink to exactly `count`)
    rather than by an off-by-one-prone loop bound.

    **Finger-friendly stepping.** Add `#windDialMinus` and `#windDialPlus` buttons either side of
    `#windDial`, each at least 44px square with `touchAction:"manipulation"`, stepping the count by
    5 and routing through `windSetDotCount` so they inherit the same clamp. A slider alone is hard
    to land on an exact value with a thumb; the steppers are what make "lock it to exactly 10" for
    D-06 run 2 a reliable action on a phone. Add a third control `#windDial10` that jumps straight
    to `WIND_DOT_DEFAULT`, so run 2's lock value is one tap.

    Every one of these is a real `button` element where the visible control and the tap target are
    the same node.
  </action>
