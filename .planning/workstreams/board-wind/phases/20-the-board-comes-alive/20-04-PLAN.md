<objective>
Make the dot field look like blowing dust rather than a grid of identical pips on a shared metronome:
give every dot its own sway rhythm and its own size with a soft edge, and confirm the layer sits in
front of the ships. Narrow the compositor guard's blanket ban in the same commit as the styling that
trips it, so the suite never goes red for a rule the phase deliberately changed.

Purpose: Wyatt's reference image for this whole layer is "blowing dust particles — they don't all
rush one way at once." The sway is already a sine wave; the problem is that its period is a single
shared constant, so the whole field breathes together. That is a one-line diagnosis with a one-draw
fix, and it is the difference between the layer reading as weather and reading as a screensaver.

Output: six seeded values per dot in a documented order, per-dot size and soft edge, a named and
asserted stacking constant, and a compositor guard that still catches BUG-01 without flagging a
compositor-safe fill.
</objective>
