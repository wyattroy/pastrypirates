  <action>
Create `src/shared/audio.js` as a `shared`-tier leaf module. Two structural rules govern the whole
file. First: it imports nothing from anywhere under `src/` — the tier rule `scripts/module_graph_check.js`
enforces automatically against every new file. Second: it constructs nothing at module load — no
`AudioContext`, no `document` access, no `localStorage` read at top level — so the module imports
cleanly under Node, where `window`, `document` and `AudioContext` are all undefined. Rule two is a
hard requirement from `21-VALIDATION.md`, not a preference: Task 2's harness cannot exist without it.

Module-level pure data, all exported, all safe to import headlessly: `SFX_DIR` for the `sfx/` path
prefix; `SFX_FILES` for the six stems `battle-swords`, `coin-flip`, `fishing`, `ship-move`,
`store-ingredient`, `storm` — this closed literal array is the only source of a fetch URL anywhere
in the module, never a runtime string (threat T-21-02); `SFX_VOLUME`, a per-stem relative-gain table
with every stem defaulting to 1, declared as the single tuning point for loudness normalising
(CONTEXT § Claude's Discretion) so a by-ear browser pass adjusts one number per sound without
restructuring; `MUTE_KEY` holding the localStorage key literal `pp_muted`.

The audio graph is lazy and built by `initAudio()` and by nothing else. It resolves
`window.AudioContext || window.webkitAudioContext` and returns silently when neither exists, so an
unsupported browser degrades to a fully playable silent game — the project's existing
silent-failure-for-optional-operations convention, cf. `iconAt()`'s image-load fallback. It creates
one `AudioContext`, creates `masterGain` connected to `ctx.destination`, fetches and
`decodeAudioData`s each stem in `SFX_FILES` exactly once into a `buffers` object keyed by stem, and
registers the `visibilitychange` listener here rather than at module load. `initAudio()` is
idempotent — a second call returns immediately.

`play(name, opts)` is the private primitive. It returns immediately when `ctx` or `buffers[name]`
is missing. It creates a FRESH `AudioBufferSourceNode` per call, connected through a fresh per-play
`GainNode` carrying `SFX_VOLUME[name]`, into `masterGain` or into the bus `opts.bus` names, then
starts it and returns the pair so a caller can hold on to it. A new source node per call is exactly
what makes repeats layer instead of cutting each other off, per D-10 — never reuse a node, never
restart one, never drop a play because another is already running. Restart-on-retrigger and
ignore-while-playing are both explicitly rejected behaviours.

`playFlip()` is exported and calls `play("coin-flip")`. Nothing else.

Mute (D-13) and the master level (D-12): `isMuted()` returns a module-level cached boolean, seeded
on first call from `localStorage.getItem(MUTE_KEY) === "1"` inside a try/catch, mirroring
`toggleTimer()`'s shipped write at `src/orchestrator.js:168` exactly — same `pp_` prefix, same
`"1"`/`"0"` string encoding, same swallowed exception. Any stored value other than the literal `"1"`
reads as unmuted (threat T-21-01); never `JSON.parse` it, never use it as a key or a path.
`setMuted(v)` updates the cache, writes localStorage inside a try/catch, and calls
`applyMasterGain()`. `applyMasterGain()` is the one place the master level is decided: the target is
0 when muted or when `document.hidden`, otherwise 1, applied through
`masterGain.gain.setTargetAtTime(target, ctx.currentTime, 0.05)` — a ramp, never a bare assignment —
so mute and tab-blur can never fight each other. The `visibilitychange` handler registered by
`initAudio()` calls `ctx.resume()` with a `.catch()` (required on iOS Safari, where a backgrounded
context enters an interrupted state and will not resume on its own) and then `applyMasterGain()`,
satisfying D-12 in both directions. Every exported function must be safe to call when `ctx` is still
null — each returns early rather than throwing.

Export style: no default export, one trailing named `export { ... }` list mirroring
`src/shared/index.js:213`. Head the file with a comment in the same voice as
`src/shared/index.js:1-6` stating the deliberate deviation — this shared module does touch
`AudioContext`, `document` and `localStorage`, unlike the tier's stated purity bar — together with
the compensating rule that keeps the tier honest: it touches all three only from inside
`initAudio()`, `isMuted()` and `setMuted()`, and never at module load.

Then hook the flip. In `src/ui/board.js`, import `playFlip` from `../shared/audio.js` (ui may import
shared directly) and call it in the `state==="spin"` branch of `setFlipCoin()`. That one branch is
reached from every flip in the game on both host and guest: `broadcastFlip("spin")` at
`src/orchestrator.js:466` and `:481` covers battle flips human and bot,
`netHandlers().onBroadcastFlip("spin")` from `humanFlip()` and `fishCast()` in `src/ui/flow.js`
covers dock and fishing flips, and `watchFlip()` at `src/orchestrator.js:141` mirrors all of them
onto guests. That is D-02 — every flip, battle rounds and routine docking flips alike — and D-07 —
the whole table, not only your own seat — satisfied at one seam with no per-seat gate. Do not add an
`appState.mySeat` or `isLocalTo` check anywhere on this path.

Finally the unlock. In `src/orchestrator.js` `wireLobby()`, register one-shot `pointerdown` and
`keydown` listeners on `document` that call `initAudio()` once and then remove both. The resume must
be fire-and-forget with a `.catch()`, so a rejected promise can never block the game action the
gesture rode in on (threat T-21-04). Do not call `initAudio()` from inside `playFlip()` or any
per-play path, and never await a resume there: unlock is a once-per-page-session concern, and
awaiting it in a hot path visibly desyncs the sound from the animation it accompanies. A
document-level gesture listener is chosen over binding one specific button deliberately — it
survives future welcome-screen changes and never has to know that `#flipCoinWrap` is not an `.apBtn`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser localStorage → page JS | `pp_muted` is user-writable from devtools or any script on the origin |
| same-origin static assets → page JS | `sfx/*.mp3` fetched by the page; already-committed, already-reviewed files |
| user gesture → AudioContext | the one-shot unlock rides on a real click that also does game work |

No new network endpoint, no new Firebase node, no new user-supplied string rendered into the DOM.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-01 | Tampering | `pp_muted` localStorage read in `isMuted()` | low | mitigate | Read inside try/catch and compare with `=== "1"`; any other value reads as unmuted. Never `JSON.parse`, never used as a key, index or path. Asserted headlessly by `scripts/audio_mapping_test.js`. |
| T-21-02 | Tampering | sfx fetch URL construction in `initAudio()` | medium | mitigate | The URL is built only from the hardcoded `SFX_FILES` literal array joined to `SFX_DIR` — never from `e.t`, a localStorage value, or any other runtime string. `scripts/audio_mapping_test.js` asserts every referenced stem resolves to a real file. |
