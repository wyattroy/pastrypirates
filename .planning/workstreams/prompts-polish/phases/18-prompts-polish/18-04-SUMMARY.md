# Phase 18 Plan 04: An Empty Hold Is Not a Bribe Summary

**`src/orchestrator.js`'s battle event now carries a real `spoilChosen` signal (set only inside the genuine-choice branch), and `src/ui/util.js` uses it to give an empty-hold loser their own "gives up 5🌕" line instead of the bribe wording — while every engine-generated, replayed, and fixture event keeps rendering byte-for-byte as before.**

## Performance

- **Duration:** ~55 min (2 task commits + 1 copy-ledger docs commit)
- **Tasks:** 2 of 2
- **Files modified:** 5 (`src/orchestrator.js`, `src/ui/util.js`, `scripts/narration_test.js`, `art-review/narration-inventory.json`, `.planning/todos/pending/copy-shipped-vs-approved-gate.md`)

## Accomplishments

- **FIX-07 fixed at the source:** `src/orchestrator.js`'s `asyncBattle` now declares `spoilChosen=false` alongside `spoil`/`spoilIng`, sets it `true` as the first statement inside the `canCoins&&hasIng` branch — the ONLY reachable point where a genuine choice is offered (human via `ask()`, bot via its needs filter) — and carries it on the `appState.game.ev({t:"battle",...})` payload. `src/engine/index.js`'s parallel simulator-only spoil branch is untouched, confirmed byte-identical to pre-plan HEAD.
- **The three-state fork:** `src/ui/util.js` replaced the old `spoilN>=5` coin-count proxy with `hasChoice` (true only when the event carries a boolean `spoilChosen` key), `isBribe` (requires the amount gate in both forks, plus `spoilChosen===true` when known), and `isEmptyHoldFive` (requires `hasChoice`, `spoilChosen===false`, and the amount gate). Absent-field events — every engine, replay, simulator, and fixture event — fall back to the exact pre-existing proxy, so their rendering is byte-unchanged.
- **The give-up line, ruled verbatim:** added to both the neutral/winner `spoilClause` if/else chain (`{loser} gives up {spoil}.` / `Ye give up {spoil}.`) and the separate loser-addressed composite chain (`${head} — ye give up ${spoilText}.`), positioned after the bribe branch and before the all-they-have fallback in each.
- **The bug-encoding test, split and extended:** `scripts/narration_test.js`'s single 5-coin assertion (which could not distinguish a genuine bribe from an empty hold) is now three labelled cases — genuine-bribe, empty-hold, absent-field-regression — each asserting mutual exclusivity of the three framings, plus dedicated loser-addressed-composite coverage for the empty-hold case, plus the 0/1/2/4-coin cleaned-out loop extended across all three `spoilChosen` states (36 assertions).
