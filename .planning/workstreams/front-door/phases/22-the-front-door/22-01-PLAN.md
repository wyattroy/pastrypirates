<objective>
Move the captain-naming moment off the welcome screen and into a modal that appears after the
player has picked how to play (FIX-01), so nobody ends up as a captain they never chose.

Purpose: the welcome-screen field is skippable, and when it is skipped `requireName()` silently
returns `DEFAULT_NAMES[0]` — the same string shown as the field's own placeholder. That is exactly
how players "end up as a captain they never chose." D-01 removes the field entirely so there is one
naming surface, not two that can disagree.

Output: a `#nameModal` overlay, a durable `pp_lastName` store, one read chokepoint that all five
former DOM readers go through, and the project's browser-automation doc updated in lockstep.
</objective>
