## 4. THE PATTERN OF THE WEEK — six instruments, one cause

**The v2.0 cutover promoted `4/` to the root, and six tools kept naming the old tree. Not one
failed loudly.**

| | what it did | how it presented |
|---|---|---|
| browser fleet | navigated to `/4/` | loaded a **directory listing** — HTTP 200, no game |
| the docs | cited `4/src/…` in 35 lines | told sessions to edit files that do not exist |
| gear picker | filtered on `4/` | **every game change reported "GEAR: NONE"** |
| `sea_trial.mjs` | read its stamp from `4/src/…` | **crashed before sailing a leg** |
| the gear HOOK | matched `4/src/` | **never fired on a single game edit** |
| `4/scripts/lib/` | aimed at `4/`'s engine | aimed at a deleted tree |

**A directory listing answers 200. A missing file makes a picker say "nothing changed". A hook
that matches nothing exits silently and looks like consent.**

### The gates that now make this class loud

`tree_health_check.js` (the chain's own paths resolve) · `game_url_check.js` (the fleet points at
a page that really contains the game) · `doc_command_check.js` (every `node …` command and link in
the docs exists) · `gate_count_check.js` (declared = run) · `gear.mjs` + `qa-gear-first.cjs`
(what counts as game code, by EXCLUSION, strict by default, **one shared definition** —
`.claude/hooks/lib/game-code.cjs`).

> **The reusable lesson: A HAND-KEPT LIST OF WHAT TO GUARD ROTS EXACTLY LIKE THE THING IT GUARDS.**
> Every gate above DERIVES its answer — from `.gitignore`, from the directory, from
> `package.json`'s own chain — rather than from a list somebody typed.

### STEP 0 of the QA loop, new today

**WIDEN THE TIME HORIZON: what happened immediately BEFORE the bug? And before that?**
A bug you cannot explain from its own moment is usually the consequence of a preceding one, and
**a snapshot cannot show you a race. INTERMITTENT IS THE TELL.** In `CLAUDE.md` (rule 6's family),
`docs/QA-PROCESS.md`, and **printed by `qa-gear-first.cjs`** when you are about to edit game code.

### And a Stop hook

`.claude/hooks/playtest-checklist-last.cjs` **blocks the end of any session that changed game code
without producing a checklist newer than that change.** mtime, not existence — a stale sheet is
worse than none, because he would test the wrong things and report them green.
