# Battle Sound at Engage Summary

Moved the battle sword-clash sound effect from the end of a fight to the beginning, per Wyatt's
playtest note: "I did hear battle sound -- just not where I expected it. move the battle sound to
the beginning of attack when battle is first engaged, not the end."

## Accepted Timing Variance (host vs. guest)

The host fires the clash on the opening announcement (flash()'s synchronous onBroadcast). The
guest fires on the first write to the Firebase battle node -- the first renderBattle() -- which
happens after flash()'s hold and after collectSideBets, which can put a human spectator through two
prompts. On a table with human spectators, the guest's clash can therefore trail the host's by
several seconds.

This is accepted, not a bug: it is still before the first coin flip, and it still lands on the
guest's own visible engage moment (the battle scoreboard appearing), so "sound played at the end of
the fight" is fixed on both tiers. Two tighter alternatives were considered and rejected in the plan
(hooking on narration text -- brittle; writing the battle node earlier -- would silence
showNarration for guests, a regression). Closing this gap fully would need a new synced field,
which is out of scope for this fix.

Flagged for Wyatt to judge live during Check C (two-tab multiplayer human verification, see
Outstanding below).

## Bakeoff Exclusion

The bakeoff drives the same scoreboard path (asyncBakeoff -> onRenderBattle -> netSetBattle), so an
ungated guest edge would have created a NEW asymmetry -- guest clash at bakeoff start, host silent
-- that didn't exist before this change. Gated out on both tiers via the title discriminator
(battleSnapshot only copies title when defined; asyncBakeoff's base() is the only producer of one).
Net effect: bakeoff audio behavior is byte-identical to before this change -- still silent per the
existing EVENT_SOUND.bakeoff: null (D-06).

Open one-line reversal if Wyatt wants the bakeoff to clash too: drop the title gate on either tier
(or both) -- that is a design call for him, not a side effect of this timing fix.
