# Quick Task 260801-84s: Integrate brass sound/mute icons into assets/icons

## Goal

Take the two user-approved brass icons staged in `art-review/icons-sound/` and ship them as
real game assets, following the crop/key/resize pipeline in `notes/art-generation-process.md` §7.

## Context

Generated this session via the `notes/art-audit.md` runbook (batch `icons-sound`). Wyatt approved
the brass versions: "perfect -- they look great, finish the process."

The game has **no** sound or mute UI control today — there is no 🔊/🔇 anywhere in `index.html`
or `src/`. So this task ships the assets only. It does **not** invent a mute feature or a call
site; wiring happens whenever that feature is actually built.

## Tasks

### Task 1 — Crop, key, and resize the two source PNGs

**files:** `art-review/icons-sound/sound-{on,off}.png` (read), `assets/icons/sound-{on,off}.png` (write)

**action:** Apply `notes/art-generation-process.md` §7 in order:
1. Sample the four corners to detect the background color (do not assume `#000001`).
2. Build a foreground mask by color distance.
3. Zero out the bottom-right ~15% exclusion zone (Gemini watermark sparkle).
4. Label connected components on an 8x-downsampled mask; keep components ≥0.05% of image area
   (must keep the detached sound-wave arcs and the detached X, which are separate components).
5. Crop to the union bbox of kept components + ~1% pad. Preserve natural aspect ratio — do NOT
   force square.
6. Chroma-key to real alpha **at full resolution, before resizing**, using an edge-flood-fill so
   only background connected to the crop border is keyed (dark interior shading stays opaque).
7. Premultiply RGB by alpha, Lanczos resize so the long side is 128px, then un-premultiply.

**verify:** Both outputs exist, are RGBA, long side 128px, aspect ratio within 1% of the cropped
source. Visually check at pixel level for staircasing on curves; composite against near-black
(the real in-game background) to catch interior holes, not just against white.

**done:** `assets/icons/sound-on.png` and `assets/icons/sound-off.png` land next to the existing
76 icons at comparable size (~10-30 KB).
